# Bolt

**Bolt** is a fast, lightweight npm client written in Rust, designed to make installing and managing JavaScript packages as efficient as possible.

## ⚡ Why Bolt?

Bolt focuses on three things:

* 🚀 **Speed** — Built in Rust for fast package operations.
* 🪶 **Lightweight** — Minimal overhead and low resource usage.
* 📦 **npm-compatible** — Designed to work with the npm ecosystem.

## 🎯 Goals

Bolt aims to provide a faster and more lightweight alternative to traditional JavaScript package managers while maintaining compatibility with the npm ecosystem.

## 🛠️ Built With

* **Rust** — High performance and memory efficiency
* **npm ecosystem** — Compatible with existing JavaScript packages
